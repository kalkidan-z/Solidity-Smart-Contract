## 🛠 Technical Competencies
Throughout this project, we implemented and mastered the following blockchain concepts:

### 1. Governance & DAO Architecture
Created Sybil-resistant voting systems that utilize low-level .call() logic to execute proposals automatically upon reaching a quorum.

### 2. Object-Oriented Smart Contracts
Engineered modular contract hierarchies using Abstract Contracts and Polymorphism. This allowed us to build reusable "Hero" frameworks where specific behaviors (like Warrior vs. Mage) override base logic.

### 3. Multiple Inheritance & Mixins
Demonstrated clean code practices by utilizing "Mixins" (Ownable and Transferable modules) to build complex functionality like secure "Collectibles" through C3 Linearization.
